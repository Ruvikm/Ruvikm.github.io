Nplayer访问电脑共享文件夹，显示Permission denied(13)
发表于2026-03-06|个人笔记
我的环境 系统：Windows 11 登录：Microsoft 账号 nPlayer：通过 IP 连接 SMB 问题：nPlayer 访问共享时报错：Permission denied (13) 当时已经开了 SMB1 之前一直报错，尝试了很多方法都不行，一直是下面这个问题。后来新建了一个用户是成功了，但是总觉的不太满意，于是后来在G老师的帮助下，找到了非常满意的解决方案 后来在微软官网社区看到的一个大佬的解决方案：在 Windows 终端 / CMD 里执行： runas /user:MicrosoftAccount\你的微软邮箱 winver 然后输入你的微软账号密码，输入的时候看不到是正常的 这个原理是先“触发/缓存”一次微软账号密码认证 然后在Nplayer里使用微软账号的邮箱，密码登录 之后就可以访问了

复制VMware虚拟机后的网络配置
发表于2025-08-30|个人笔记
